# NETZWERK – Die Störungsleitstelle (Arbeitstitel)

Konzept für ein browserbasiertes Leitstellen-/Aufbauspiel: Der Spieler führt die Entstörungs- und Servicezentrale eines Infrastruktur-Dienstleisters (Strom, Gas, Wasser, Abwasser, Verkehrstechnik, Telekom, Winterdienst) und erfüllt **auftragsgebundene Einsätze** mit Fristen, Vergütung und Vertragsstrafen.

➡️ Vollständiges Konzept: [docs/spielkonzept.md](docs/spielkonzept.md)

🎮 Spielbarer Prototyp: [game/](game/README.md) – `game/index.html` im Browser öffnen.
